# Rank Night

Rank Night is a standalone TV party game. It does not use the blog layouts,
stylesheet, configuration, or post system.

The game includes 12 built-in topic packs with 20 cards in every pack and
generates a local PNG image for every item card. The ranking board keeps the
five S, A, B, C, and D tiers. SortableJS 1.15.7 provides mouse and touch
drag-and-drop support. Arrow keys plus Enter provide single-remote controls.

Finished rankings are saved to local browser storage and can be viewed or
deleted from the Rankings menu. No data is sent to a server.
